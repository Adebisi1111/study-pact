# Study Pact — contract

Rust NEAR contract for Study Pact: a commitment contract for study sessions where no-shows forfeit their deposit.

Full project README, "do X — see Y" steps, design decisions, and known limitations: [../README.md](../README.md).

## Quick start

```bash
cargo test                                          # 13 unit tests
cargo near build non-reproducible-wasm             # build
```

Deployed on testnet at `studypact-adebisi.testnet`.
