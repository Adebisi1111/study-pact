# Study Pact — frontend

React + Vite web UI for Study Pact: wallet connect, create/join/check-in/settle, session status, and a cross-chain quote preview.

Full project README, "do X — see Y" steps, NEAR tools, and known limitations: [../README.md](../README.md).

## Quick start

```bash
cp .env.example .env   # points at studypact-adebisi.testnet (testnet)
npm install
npm run dev
```
